# repoctl brand assets

repoctl's mark shows three workspace nodes converging into a terminal prompt. It is a compact reminder that repoctl turns repository structure into executable tasks.

## Palette

| Use      | Light     | Dark      |
| -------- | --------- | --------- |
| Graphite | `#20252d` | `#f4f6fa` |
| Cobalt   | `#2457d6` | `#6f94ff` |

The primary lockup uses graphite for the connector and wordmark, with cobalt for the nodes and prompt. The dark lockup uses the dark cobalt mark and a light wordmark. Mono variants are available in black and white for one-colour production.

## Usage

- Keep clear space equal to the height of the prompt mark on every side.
- Use the standalone mark at 16px or larger; use the lockup at 120px wide or larger.
- Keep the mark flat and unmodified. Do not add gradients, shadows, outlines, enclosing shapes, rotations, stretched proportions, or extra slogans.
- Use the dark variant on graphite or other dark backgrounds, and the primary variant on light backgrounds.

The SVG files in `svg/` are the source of truth. They contain paths only and do not require a font. Raster exports are provided for product surfaces and social sharing. `logo.jpg` is retained as a flattened 640px compatibility export for integrations that still request the old path.
