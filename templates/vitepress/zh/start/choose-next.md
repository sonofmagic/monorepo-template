# 选择下一项任务

先按你要得到的结果选择任务。每个任务页都包含适用场景、前置条件、最小命令、预期输出、常见分支和下一步。

| 目标                          | 进入                                           |
| ----------------------------- | ---------------------------------------------- |
| 把 repoctl 接入已有 workspace | [接入已有 workspace](/zh/tasks/adopt-existing) |
| 创建包、应用、服务或文档站    | [创建包或应用](/zh/tasks/create-project)       |
| 提交前运行本地校验            | [运行校验](/zh/tasks/checks)                   |
| 保存评审或排障需要的输出      | [报告与输出](/zh/tasks/reports)                |
| 把同一套流程接入 CI           | [把校验加入 CI](/zh/tasks/ci)                  |
| 准备发布包                    | [发布包](/zh/tasks/release)                    |

参数和分组命令请查看[命令参考](/zh/reference/commands)。想了解命令为什么这样执行，可以阅读[repoctl 执行模型](/zh/reference/execution-model)。
